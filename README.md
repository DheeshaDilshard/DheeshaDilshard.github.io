# Dheesha Dilshard — Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Deploy
Upload the whole folder to a static hosting service such as GitHub Pages, Vercel, Netlify or another static host.

## Replace project links
The three project cards currently use placeholder links (`#`). Replace them with your actual GitHub repository/demo URLs when available.
